# 레시피 저장소 '추천 레시피' 작성 규칙

앱 레시피 탭 맨 아래에 3일마다 새 판(레시피 3개)이 나와요. 사용자는 마음에 드는 레시피를 내 레시피로 저장해 그대로 따라 해요.
그래서 레시피는 집에서 처음 해 보는 사람도 실패하지 않을 만큼 정확하고 친절해야 해요.
말투: 소개(intro)·팁(tip)·판 제목·한마디(note)는 해요체, 조리 단계(steps)는 "~한다"로 끝나는 짧은 문장.
자료 문장을 베끼지 말고 네 말로 새로 써.

## 1. 무엇을 고를까
- 한국 가정의 흔한 도구(냄비·프라이팬·전자레인지, 있으면 에어프라이어·오븐)로 1시간 안팎이면 만드는 요리. 손님상은 90분까지.
- 재료는 동네 마트·시장에서 쉽게 사는 것. 구하기 어려운 수입 재료, 특수 도구(수비드·훈연기 등)는 빼요.
- 제철: 그 달 제철 재료(아래 7번 표)를 판마다 1개 이상 주인공으로 써요. 두부·달걀·양파처럼 1년 내내 나오는 재료는 곁들이로.
- 판 구성(레시피 3개, 이 순서로):
  1. 국·찌개 또는 메인 요리(조림·구이·찜) 1개
  2. 반찬·볶음 1개
  3. 면·밥 / 간식 / 양식 / 손님상 중 1개
- 한 판 안에서 주재료(소고기·돼지고기·닭·생선·해산물·버섯 등)가 겹치지 않게 해요.
- 지난 판들(`round.py status`의 recentRounds)과 분류·조리법이 겹치지 않게 돌려요. 예) 지난 판 3번째가 간식이었으면 이번엔 면·밥이나 양식.
- 관리자 요청(`pipeline/requests.json`)이 있으면 먼저 써요. 제철이 아니어도 요청이면 써요.
- 최근 120일에 추천한 요리(status의 recentTitles)는 안 돼요. 이름만 다른 같은 요리('소고기 뭇국'과 '쇠고기무국')도 피해요.

## 2. 정확성(가장 중요)
- 분량·불 세기·시간은 믿을 만한 자료 2곳 이상을 교차 확인해 정해요. 자료가 서로 다르면 가운데 값이나 더 안전한 값(덜 짜게, 충분히 익게)으로.
  - 참고할 만한 곳: 만개의레시피(조회·후기가 많은 글), 농촌진흥청 농식품올바로(메뉴젠), 식품안전나라 레시피, 한식진흥원,
    요리 연구가·유명 요리 채널(백종원 등)의 영상 내용·글, 믿을 만한 언론의 레시피 기사.
- 베끼지 않기: 문장이나 문단을 그대로 옮기지 않아요. 확인한 사실(분량·시간·온도)만 가져오고 글은 새로 써요.
- 2인분이 기본(servings 2). 국물 요리는 2인분 물 600~800ml 안팎, 간(간장·소금·액젓)은 조금 적게 넣고 마지막에 "간을 보고 소금으로 맞춘다".
- 단계에 쓰는 재료는 모두 재료 목록에 있고, 목록의 재료는 모두 단계에 나와요. 목록은 대체로 쓰는 순서대로.
- 다 만든 양·맛이 상상되지 않으면 자료를 하나 더 확인해요. 그래도 자신 없으면 다른 요리로 바꿔요.

## 3. 안전
- 고기·닭·오리·해산물은 속까지 완전히 익혀요. 익었는지 아는 표시를 단계에 적어요.
  - 돼지고기·닭: "속까지 분홍빛이 없고 맑은 육즙이 나오면"(닭은 가장 두꺼운 곳을 찔러 봐요). 다진 고기도 속까지.
  - 새우: "주황빛으로 변하고 몸이 둥글게 말리면". 조개: "입을 벌리면(끝까지 안 벌린 것은 버린다)". 생선: "살이 하얗고 쉽게 갈라지면".
- 날달걀·반숙이 들어가는 요리는 되도록 피해요. 쓰면 tip에 "신선한 달걀을 쓰고, 어린이·임신부·노약자는 완전히 익혀 드세요".
- 회·생굴처럼 날로 먹는 해산물 요리는 추천하지 않아요. 굴은 익히는 요리로.
- 뜨거운 기름·설탕 시럽·튀김: 물기 닦기, 기름 튐·화상 주의를 단계나 tip에 적어요.
- 재우기·불리기는 "냉장고에서 30분"처럼 장소를 적어요. 고기·해산물을 상온에 오래 두는 단계는 쓰지 않아요.
- 술(청주·맛술)은 잡내 빼기용 소량만. 아이가 먹는 간식에는 쓰지 않아요.

## 4. 형식 (validate.py가 검사해요)
| 칸 | 규칙 |
|---|---|
| title | 1~20자. 요리 이름만("소고기 뭇국", "느타리버섯 들깨볶음"). 따옴표·괄호·꾸밈말 없이 |
| intro | 1~60자. 해요체 한 문장. 어떤 맛인지, 왜 지금 맛있는지 |
| tags | 1~3개, 각 1~12자. 되도록 `찌개·국` `볶음` `면·밥` `반찬` `한식` `양식` `손님상` `간식`에서(다른 태그는 경고) |
| servings | 정수 1~20. 기본 2 |
| minutes | 정수 1~999. 손질부터 완성까지 모두(담그기·재우기 포함). 단계 timer를 더한 값보다 커야 해요 |
| ingredients | 2~30개. `{ "name", "qty", "unit" }` (5번) |
| steps | 2~12개. `{ "text", "timer" }` (6번) |
| tip | 0~120자. 해요체. 실패를 막는 요령 하나나 바꿔 쓸 재료. 없으면 "" |

- 모든 글: 앞뒤 공백 없이, 이모지·주소(URL)·줄바꿈 없이, 상표 이름 없이.
- 레시피 하나를 쓸 때 id는 넣지 않아요(합칠 때 `rec-YYMMDD-n`이 붙어요).

## 5. 재료 이름과 분량
앱은 사용자의 냉장고 재료와 레시피 재료를 이름 글자로 맞춰 봐요. 그래서 이름은 짧고 일반적으로 써요.
- 기본 이름: 대파, 쪽파, 양파, 무, 두부, 달걀, 감자, 애호박, 느타리버섯, 고등어.
- 부위·형태를 붙일 때는 기본 이름이 그대로 들어가게: '돼지고기 앞다리살'('돼지고기' 포함), '소고기 양지', '다진 마늘', '닭다리살'.
- 표기 통일: 달걀(계란 ×), 소고기(쇠고기 ×), 후춧가루(후추 ×), 고춧가루, 들깻가루, 통깨, 국간장·진간장(그냥 '간장'은 진간장 뜻일 때만).
- 괄호·숫자·쉼표·설명을 넣지 않아요: '고춧가루(고운 것)' ×. 설명은 단계나 tip에.
- 상표 이름 금지: '백설 올리고당' → '올리고당'. 조미료 상품명(다시다·연두 등)은 일반 재료로 바꿔요.
- 같은 재료는 한 줄로 합쳐요. 밑간과 양념에 나눠 쓰면 합친 양을 적고 단계에 "국간장 절반"처럼 써요.
- 물·육수도 양이 중요하면 재료에 넣어요.

### 단위 (이 16개만)
| 단위 | 쓰는 곳 | 예 |
|---|---|---|
| g, kg | 고기·생선·채소 무게 | 소고기 양지 150g, 배추 1.2kg |
| ml, L | 물·육수·우유 | 물 800ml, 물 1.5L |
| 큰술 | 양념·기름·가루 (1큰술 = 15ml) | 국간장 1큰술 |
| 작은술 | 적은 양념 (1작은술 = 5ml) | 다진 마늘 1작은술 |
| 컵 | 쌀·물·기름이 많을 때 (1컵 = 200ml) | 식용유 1컵 |
| 개 | 양파·감자·달걀·고추·호박 | 양파 0.5개 |
| 쪽 | 통마늘 | 마늘 3쪽 |
| 대 | 대파·쪽파 | 대파 0.5대 |
| 모 | 두부 | 두부 1모 |
| 줌 | 시금치·콩나물·부추처럼 한 손에 쥐는 양 | 시금치 1줌 |
| 장 | 김·깻잎·만두피 | 깻잎 10장 |
| 포기 | 배추·청경채 | 배추 0.25포기 |
| 꼬집 | 엄지·검지·중지로 집은 아주 적은 양 | 소금 1꼬집 |
| 약간 | 간 맞추기·마무리(소금·후춧가루·통깨). qty는 null | 후춧가루 약간 |

- 1큰술 = 15ml = 3작은술, 1작은술 = 5ml, 1컵 = 200ml.
- 자료가 숟가락·스푼·종이컵으로 적었으면 위 단위로 바꿔요. 밥숟가락은 큰술보다 조금 작고(10~12ml), 종이컵은 약 180ml예요.
- qty 맞추기
  - 큰술·작은술·컵·대·모·줌: 0.5 단위(0.5, 1, 1.5). 0.5보다 작으면 한 단계 작은 단위로(0.5큰술 미만 → 작은술, 0.5작은술 미만 → 꼬집이나 약간).
  - 개·포기: 0.5 단위, 꼭 필요하면 0.25(양파 0.25개, 배추 0.25포기).
  - g: 100g 미만은 5g 단위, 100g 이상은 10g 단위. 1000g 이상은 kg(1.2kg).
  - ml: 100ml 미만은 10ml 단위, 그 이상은 50ml 단위. 1000ml 이상은 L(1.5L).
  - 소수는 둘째 자리까지. qty는 숫자(문자 "1/2" ×, 0.5 ○).
- 단위가 '약간'이면 qty는 null, 그 밖의 단위는 0보다 큰 숫자(최대 10000).

## 6. 조리 단계
- 2~12단계, 한 단계 5~200자, 1~2문장. 손질 → 밑간 → 익히기 → 간 맞추기 → 마무리 순서.
- 불 세기를 꼭 적어요: 센불·중불·중약불·약불. 오븐·에어프라이어는 온도도("180도에서").
- 다 됐는지 아는 표시를 적어요: "양파가 투명해지면", "젓가락이 쑥 들어가면", "국물이 반으로 줄면", "겉이 노릇하면".
- 썰기는 크기를 적어요: "3cm 크기", "0.5cm 두께", "한입 크기".
- timer(분)는 기다리는 단계에만: 끓이기·졸이기·삶기·찌기·굽기·튀기기·불리기·담그기·재우기·뜸 들이기·식히기.
  1~3분 볶기처럼 손을 계속 쓰는 짧은 단계는 0이에요.
  - 글에 같은 시간을 적어요: timer 20 → "20분 끓인다", timer 60 → "1시간 재운다". 다르면 validate.py가 경고해요.
  - 앱 타이머는 하나라서 "15~20분"처럼 범위로 쓰지 말고 하나로 정한 뒤 다 된 표시를 함께 적어요.
  - 한 단계에 기다림이 두 번이면 단계를 나눠요.

## 8. 판 제목과 한마디
- 판 title 1~30자: 짧고 다정하게, 계절이 느껴지게. 예) "햇무와 버섯이 맛있는 가을 밥상", "선선한 가을, 따끈한 한 그릇".
- note 0~80자: 해요체 1~2문장. 왜 이 요리들을 골랐는지. 예) "무와 버섯이 맛있어지는 때라 국물 요리와 밥반찬으로 골랐어요."
- '오늘·내일·이번 주'처럼 읽는 날에 따라 뜻이 바뀌는 말은 쓰지 않아요. 판은 며칠 동안 보여요.
